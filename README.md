# 🍔 LunoBite — Let Us Crave With You

**LunoBite** is a modern, user-friendly food delivery website designed to make discovering delicious meals, exploring restaurants, and ordering food simple and enjoyable. With a youthful design, soft lavender accents, charcoal text, and a clean interface, LunoBite brings a fresh and welcoming experience to online food ordering.

## 🌟 About the Project

LunoBite was created to provide users with a convenient way to explore food options in one place. From fast food and refreshing drinks to sweet ice cream treats, the platform allows users to browse different categories, discover restaurants, and explore menu items through an attractive and responsive interface.

The project focuses on combining appealing visual design with practical functionality to create a smooth food-ordering experience.

## ✨ Features

- **🏠 Home Page:** A welcoming landing page featuring food options and restaurant recommendations.
- **🍕 Food Categories:** Explore fast food, drinks, ice cream, and other delicious options.
- **🔍 Food Discovery:** Browse available food items and restaurants.
- **🛒 Shopping Cart:** View selected items and review your order.
- **❤️ Favourites:** Keep track of favourite food options.
- **👤 User Profile:** Access the profile section.
- **📍 Restaurant Information:** Explore restaurant details and location information.
- **📞 Contact Us:** A section for users to find contact information.
- **📱 Responsive Design:** A modern interface designed to adapt to different screen sizes.
- **💜 Brand Identity:** A soft lavender, charcoal, and white colour palette that creates a clean and recognisable look.

## 🎨 Design Concept

LunoBite uses a friendly, modern design inspired by the convenience of food delivery and the excitement of discovering new meals.

The design includes:

- **Lavender:** Adds personality and visual interest.
- **Charcoal:** Provides contrast and readability.
- **Soft white:** Keeps the interface clean and spacious.
- **Typography:** Modern, readable fonts that support the brand identity.
- **Interactive elements:** Buttons and navigation designed to make exploring the website easier.

The brand tagline, **“Let Us Crave With You,”** reflects LunoBite's fun and welcoming approach to food discovery.

## 🛠️ Technologies Used

- **React** — Building reusable and interactive user interface components.
- **TypeScript** — Adding type safety and improving code maintainability.
- **CSS** — Styling the website, including layouts, colours, animations, and responsive behaviour.
- **HTML** — Structuring the website content.
- **Git and GitHub** — Version control and project hosting.

## 🎯 Project Goals

The goal of LunoBite is to demonstrate practical frontend development skills through a food delivery website concept. The project explores responsive web design, reusable React components, user-friendly navigation, and interactive shopping features.
